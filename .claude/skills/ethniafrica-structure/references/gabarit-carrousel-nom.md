# Gabarit de narration du carrousel « nom de X »

Décidé avec l'opérateur le 2026-09-21. Un carrousel qui explique l'origine d'un nom
suit **cet ordre et ces champs, à chaque sujet**, pour les cinq typologies : peuple,
pays, patronyme, lieu, langue. Le but est que deux carrousels écrits à des semaines
d'écart donnent le même niveau d'information, dans la même forme.

Ce fichier remplace tout ce que GABARITS-SOCIAL §7 ter disait de la clôture d'un
carrousel : plus de clôture par type de contenu, plus de ligne de vision, plus de
renversement d'agent, plus de compte chiffré. Le gabarit du reel est un fichier
distinct ; le carrousel n'en dépend pas.

## Un sujet sans mythe sourcé n'a pas de carrousel

L'accroche est la question d'un mythe que le public tient réellement, et la deuxième
carte y répond. Si aucune fiche du corpus ne sourçait ce mythe, n'en invente pas un
pour remplir la carte : dis-le à l'opérateur. Une question dont la réponse n'est pas
dans la pièce est un appât, pas une accroche.

## L'ordre des cartes

| #     | Carte                         | Ce qu'elle dit, toujours                                                                                                                               |
| ----- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1     | **Accroche**                  | La question du mythe, en une phrase.                                                                                                                   |
| 2     | **Réponse au mythe**          | Le verdict, puis ses limites : ce qui est vrai dans l'idée reçue, ce qui ne l'est pas. Sourcé dans une fiche, jamais écrit de mémoire.                 |
| 3     | **Cadrage**                   | Un nom porte plusieurs appellations. Nous cherchons celle que le sujet se donne. D'autres lui en ont donné, parfois devenues plus connues.             |
| 4     | **Inventaire**                | Les appellations actuelles, trois ou quatre au plus. Le nom que le sujet se donne d'abord. S'il y en a plus : « N autres formes sont sur notre site ». |
| 5 à n | **Une fiche par appellation** | Six champs, toujours dans le même ordre (voir plus bas). Une carte de plus seulement si une seconde version de l'origine existe.                       |
| n+1   | **Classement**                | On relit toutes les appellations et on les range en trois statuts, une raison par nom.                                                                 |
| n+2   | **Morale**                    | Voir plus bas.                                                                                                                                         |
| n+3   | **Clôture**                   | La clôture unique, mot pour mot, en dernière carte.                                                                                                    |

Le nombre de cartes varie de 8 à 14 : les fiches et les secondes versions font varier
le milieu, jamais l'ordre. Une carte ne dit qu'une chose.

## La fiche d'une appellation

```
APPELLATION : <forme retenue>         STATUT : nom qu'ils se donnent | donné par d'autres | évité
1. Ses formes          : français · anglais · langue locale. Le problème que ces variantes posent.
2. Qui l'a donnée      : eux-mêmes, ou d'autres ? lesquels ? d'où parlent-ils ?
3. Première attestation: la plus ancienne mention connue (date, texte, auteur).
4. Version principale  : l'origine la mieux documentée, attribuée.
5. Seconde version     : une seule, seulement si elle existe, attribuée aussi.
6. Pourquoi ce statut  : une phrase. Si le nom propre n'est pas attesté : « semble lié au peuple local ».
```

- **Deux versions au plus.** La principale est la plus documentée, pas la plus flatteuse.
  Aucune n'est couronnée.
- **Le ton suit la certitude.** Sources concordantes : phrase affirmative. Sources qui
  divergent : « la version principale relie… », « une lecture y voit… ». Question non
  tranchée : « L'origine de X n'est pas établie », puis les pistes attribuées.
- **Un récit local se nomme à côté du récit extérieur**, dans la même carte, à son
  propre niveau de source. Si le corpus n'a que des sources extérieures, la carte peut le
  dire.
- **Trois ou quatre appellations au plus.** Critère de choix proposé, **en attente de
  confirmation par l'opérateur** : le nom que le sujet se donne, s'il existe ; le nom donné
  par d'autres devenu le plus connu ; le nom évité ; puis le plus anciennement attesté.

### Les trois statuts, et les mots pour les dire

| Statut sur la carte        | Le mot du métier | Quand                                                       |
| -------------------------- | ---------------- | ----------------------------------------------------------- |
| **nom qu'ils se donnent**  | autonyme         | Le sujet l'emploie pour lui.                                |
| **nom donné par d'autres** | exonyme          | Des voisins, des voyageurs, une administration l'ont donné. |
| **nom évité**              | exonyme récusé   | Le sujet le refuse, ou l'usage responsable l'écarte.        |

Sur une carte, on écrit les trois expressions de la colonne de gauche. Un mot du métier
n'apparaît que s'il est expliqué dans la phrase qui suit.

## Ce qui change selon la typologie

Le squelette et les six champs ne bougent pas. Seule la question du champ 2 s'adapte.

| Typologie               | « Qui se nomme lui-même ? » devient                                                                                      | Piège propre                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **Peuple**              | Le nom que le peuple emploie, face aux noms des voisins, des voyageurs, des administrations.                             | Le préfixe de classe (Ba-, Wa-…) qui saute ou non selon la langue. |
| **Pays**                | Le nom que l'État a choisi ou adopté, face au nom hérité ou imposé.                                                      | Un nom repris à un empire ancien ; une forme officielle ≠ l'usage. |
| **Patronyme**           | La forme d'origine face à la forme fixée par l'état civil. Le type d'origine se dit : métier, totem, éloge, lieu, nisba. | Les graphies multiples d'un même nom.                              |
| **Lieu, ville, région** | Le nom local face au nom d'explorateur, de carte ou de colonisateur.                                                     | Un nom entendu de travers, puis figé sur une carte.                |
| **Langue**              | Le nom que ses locuteurs lui donnent face au nom de catalogue.                                                           | Confondre la langue et le peuple. Le code ISO 639-3 sert d'ancre.  |

Pour un patronyme, les « appellations » sont des graphies. L'origine du nom se raconte
dans la fiche de la forme d'origine ; les autres fiches disent qui a fixé leur graphie,
et quand. Le statut « nom donné par d'autres » y devient « forme administrative ».

## La morale

Elle répond à la question posée en accroche, et à rien d'autre. Décidé par l'opérateur
le 2026-09-21 :

1. **Le titre répond.** « Non… » si le mythe est déconstruit ; « Pas directement… » ou
   « La version principale… » s'il est nuancé.
2. **Le corps dit qu'il y a eu plusieurs appellations**, puis la nuance.
3. **Sans jugement, sans agressivité.** Aucun renversement d'agent, aucune phrase de
   doctrine : ni « Ce peuple n'a pas été divisé », ni « Ce peuple n'a jamais manqué de
   nom ». Ces lignes sont retirées.

Comme toute synthèse, elle se propose à l'opérateur dans la conversation, en deux ou
trois options, avant d'être écrite dans `cards.json`.

## La clôture

Identique pour les cinq typologies, patronyme compris, et identique à celle du reel. Le
texte se prend dans GABARITS-SOCIAL §7 ter, « Le reel a un couple unique », mot pour
mot. Carte : titre = première phrase, corps = seconde. Aucune ligne de vision, aucun
`appel`, aucun `pivot`.

## Règles de rédaction

- Sujet, verbe, complément, sauf une question. Vingt mots au plus par phrase, voix
  active. Aucune carte n'ouvre par un complément (« En 1894, », « Selon lui, »).
- Un mot difficile s'explique dans la phrase qui suit.
- On écrit « notre projet », jamais « l'atlas ».
- Wikipédia ne s'affiche jamais comme source.
- Aucune datation d'origine des frontières, pas de « Berlin » comme auteur des lignes,
  pas de « mille ans » posé comme un fait.

## Les cinq exemples, tous fictifs

Ils sont **le modèle à reproduire**. Les noms, les dates et les sources sont inventés ;
ils ne se publient pas. Chaque source fictive est marquée « [fictif] ». Les cartes 1 à
n+2 sont ci-dessous ; la carte finale est toujours la clôture unique.

### Peuple : les Ondari

| #   | Carte            | Texte                                                                                                                                                                                                                                                                                                                               |

| 1   | Accroche         | « Sarkou » est-il le vrai nom du peuple ondari ?                                                                                                                                                                                                                                                                                    |
| 2   | Réponse au mythe | Non. « Sarkou » est un mot des voisins kelemi. Les Ondari ne l'emploient pas pour eux. Le mot existe pourtant depuis 1871, et c'est lui qui figure sur les cartes.                                                                                                                                                                  |
| 3   | Cadrage          | Un peuple porte toujours plusieurs noms. Nous cherchons celui qu'il se donne. D'autres peuples lui en ont donné d'autres, parfois plus connus.                                                                                                                                                                                      |
| 4   | Inventaire       | Ondari · Sarkou · Vellani. Six autres formes existent, elles sont sur notre site.                                                                                                                                                                                                                                                   |
| 5   | Fiche Ondari     | Formes : Ondari (local), Wondari (français), Ondary (anglais). Le préfixe « Wo- » vient de la langue voisine et change le nom sur les cartes. Qui : les Ondari eux-mêmes. Première attestation : le carnet du naturaliste Brandt, 1871 [fictif]. Version principale : « les gens du fleuve », selon un récit oral de 1958 [fictif]. |
| 6   | Seconde version  | Une lecture y voit « les descendants d'Onda », un ancêtre cité dans les généalogies [fictif]. Statut : nom qu'ils se donnent. Les Ondari l'emploient entre eux.                                                                                                                                                                     |
| 7   | Fiche Sarkou     | Formes : Sarkou, Sarcou, Sarkoo. Les voisins kelemi ont créé le mot. Le même carnet le note en 1871. Il veut dire « ceux d'en bas », car les Ondari vivent en aval [fictif]. Aucune autre version n'est connue. Statut : nom donné par d'autres, devenu le plus connu.                                                              |
| 8   | Fiche Vellani    | Formes : Vellani, Vellan. Une administration coloniale l'écrit en 1902 dans ses registres d'impôt [fictif]. L'origine de ce mot n'est pas établie : deux registres divergent. Statut : nom évité. Les Ondari le refusent, car il rappelle l'impôt.                                                                                  |
| 9   | Classement       | **Ondari** : le nom qu'ils se donnent. **Sarkou** : donné par les voisins, le plus connu. **Vellani** : donné par l'administration, évité.                                                                                                                                                                                          |
| 10  | Morale           | Titre : Non : « Sarkou » est le nom que ses voisins lui ont donné. Corps : Les Ondari se nomment Ondari. Ce peuple a aussi porté les noms Sarkou et Vellani. | 4   | Inventaire        | Talvane · Talvania · Côte Ombrée. Deux autres formes sont sur notre site.                                                                                                                               |

| 8   | Fiche Côte Ombrée | Nom colonial, en usage de 1895 à 1960 [fictif]. Il décrit la côte vue de la mer et ne dit rien de ceux qui y vivent. L'origine exacte du mot « Ombrée » n'est pas établie. Statut : nom évité.          |
