# Stash — one file per theme, filled over time

`$ETHNIAFRICA_SOCIAL_PROJECTS/swipe-<theme>/stash.md`. One entry per clip, in the
order they were found. Leave a field blank rather than guess it.

```markdown
# Swipe stash — lingala

## 1. <short label>

- **Source:** <file path or link>
- **Credit:** <title> · <channel or author> · <year>
- **Language:** <French | English | Lingala…>
- **Translation:** <not needed | needed, not yet received | received on YYYY-MM-DD>
- **Moments:** <1:12–1:34, 3:05–3:20 | not yet chosen>
- **Version it carries:** « <in the speaker's terms> »
- **Register:** <funny | serious | dismaying | sad | absurd>
- **Note:** <anything the operator said about why it matters>
```

The stash report (mode 1) reads these fields and nothing else. A clip with no
credit is still filed, flagged as a blocker.
