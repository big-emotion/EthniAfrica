# Running order (conducteur) — what the operator approves before any render

Written next to the stash, as `conducteur.md`. In French, because the operator
reads it.

```markdown
# Swipe — <theme> — conducteur v<n>

**Récit**

- On part de : <la version la plus répandue, ou la plus sûre d'elle>
- On confronte : <les versions qui se contredisent>
- On arrive à : <le clip qui penche, et vers quoi : sources du corpus / « rien n'est tranché »>

**Les sources penchent vers :** <une phrase, avec la fiche et ce qu'elle cite>

| #   | Vignette | Source (titre · chaîne · année) | Entrée → sortie | Durée | Ce que dit la personne | Rôle                                                |
| --- | -------- | ------------------------------- | --------------- | ----: | ---------------------- | --------------------------------------------------- |
| 1   | <frame>  |                                 | 1:12 → 1:34     |  22 s |                        | ouvre                                               |
| …   |          |                                 |                 |       |                        | contredit · surenchérit · fait rire · penche · clôt |

**Total :** <m:ss> (doit rester sous 3:00) · **Clips :** <n>
**Repères à l'écran :** <clip n° : « Kinshasa, 1974, OZRT »…>
**Traductions attendues :** <clips n° …>
**Ce que les clips affirment sans appui des sources :** <liste, ou « rien »>
```

The roles are the same words every time, so two running orders compare.
