# Descriptions per network

One description per network, in French, from the same facts. The reel and the cover
are already made; the description carries what a 2-minute clip cannot — the
attribution, the credit, and, when the cover asks a question, its answer.

## Choose the flavour first

| Flavour         | When the prompt is…                              | The first line                         |
| --------------- | ------------------------------------------------ | -------------------------------------- |
| **Debate**      | an exchange where two people hold two positions  | the question they argue, as a question |
| **Word origin** | about a name or a word — the project's own theme | « D'où vient le mot « X » ? »          |

**Debate.** Say who holds which position (« Pour l'un… Pour l'autre… »). Never take
a side, never add the project's view, never present one speaker's claim as settled.
End on an open question the reader can answer in the comments.

**Word origin.** The origin of a word is often not established: **name several paths
or none**, each attributed to who holds it, none crowned. « Son origine n'est pas
établie. Une piste… Une autre… » Then what is better known (the earlier senses, the
first attested dates), then the question the reel leaves to the reader. Check every
date and sense first — an encyclopedia read is a first pass, **never the source shown
in a caption or on screen** (operator ruling, 2026-09-21); cite a dictionary of reference
or a primary document if a source has to appear. The consultation itself is kept, dated,
in the piece's workshop record — what is displayed is restricted, what was read is not hidden. If a cover asks « qui a inventé… ? », the description must answer or
admit it cannot.

## The six

Every description **credits the source** (« Extrait de « Émission » (Chaîne),
sous-titré en français ») and, when the operator has it, links the full video.

| Network            | Shape                                                                                       | Limit and habits                                               |
| ------------------ | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **TikTok**         | The question first, two or three short lines, one invitation, the credit, three hashtags    | Only the first words are seen before « plus »                  |
| **Instagram**      | The long form: question, the positions or paths, the invitation, the credit, link, hashtags | Three hashtags at most; the link lives in the bio              |
| **YouTube Shorts** | A title (≤ 100 characters, the question) and a description of the long form                 | No hashtag needed in the body                                  |
| **Facebook**       | The long form, no hashtags                                                                  | Longer text is read; keep paragraphs short                     |
| **X**              | The question, the two poles in one breath, the credit, the link                             | 280 characters; a link counts for 23 whatever its length       |
| **LinkedIn**       | The same facts in a calmer register, framed as a definition or a method                     | No hashtags; end on a question about how the reader defines it |

## Rules that hold on all six

- **Attribute, never assert.** « Il avance que… », « pour l'un… ». A claim the
  sources do not settle is not stated flat, and is not disclaimed either: no
  « ce sont ses mots, nous ne les avons pas vérifiés ».
- **Peoples first, sources after.** Name what people call themselves and each other;
  the author or the book stays on a source line, never at the head of a sentence.
- **Close what the hook opens.** A question in the first line is answered, or its
  lack of an answer is said, before the invitation to comment.
- **No « atlas »**; « nous », « notre projet », EthniAfrica.
- **Rights are not settled by a credit line.** Say so in the final report, every time.
