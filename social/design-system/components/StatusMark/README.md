Status marks name the kind of evidence or event with a word and a shape; the same shapes build the recap timeline of a closing card.

**Provide:** `status: "origine"` (or `{kind, label}`) on any card, or `date.marker` on a dated card; `recap: [{date, name, kind}]` on the closing card of a dated sequence.

**Do:** draw a mark only for origin, context and uncertainty; let the other kinds name the kicker; let the `origine` mark carry its sentence.

**Don't:** use colour alone to signal status; invent kinds; put a timeline on the dated cards themselves.
