The explanation card carries one idea in one to three connected sentences, optionally with a forms table, a name pair or an exact quotation.

**Provide:** `type: "explanation"`, `kicker`, `title`, `body` (one to three sentences, up to about 330 characters), optional `forms`, `note`, `quote`, `status`, then `source`, `credit` and `image`; `veil: "strong"` over a printed page.

**Do:** introduce the name before explaining it; attribute every hypothesis; use a status mark when the idea is uncertain or is an origin hypothesis.

**Don't:** stack fragments; put a translation in guillemets; add a second idea instead of a second card.
