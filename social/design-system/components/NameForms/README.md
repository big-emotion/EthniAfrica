The NameForms block shows how one name changes form, or leads from the searched form to the name a people gives itself.

**Provide:** `forms: {layout: "table", rows: [["*Bu*ganda", "le pays, le royaume"], …]}` (up to four rows; mark the changing part as the accent) or `forms: {layout: "pair", searchedLabel: "Vous avez cherché", searched: "Peul", selfLabel: "Ce peuple se nomme lui-même", self: "Fulɓe"}`.

**Do:** use the pair where the reader searched an exonym (doctrine §1.1); keep glosses short and plain.

**Don't:** rank forms; uppercase them; add a gloss the sources do not give.
