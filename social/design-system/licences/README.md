# Font licences

All five font files in `fonts/` are published under the SIL Open Font License 1.1 and ship unmodified. `OFL-Noto.txt` is the full OFL 1.1 text, the same licence every family here carries.

- Anton, by Vernon Adams and the Anton Project Authors.
- Nunito Sans, by Vernon Adams and Jacques Le Bailly (variable file, weights 200 to 1000).
- Noto Sans, by the Google Noto project (variable file), used only for the African letters Nunito Sans lacks.
- Fraunces, by Undercase Type (Phaedra Charles, Flavia Zimbardi).
- Noto Sans Ethiopic, by the Google Noto project.

Noto Sans comes from the Google Fonts repository (`ofl/notosans`); the other files come from `social/brand/fonts/` in the EthniAfrica repository.
