# Font licences

All six font files in `fonts/` are published under the SIL Open Font License 1.1 and ship unmodified. `OFL-Noto.txt` is the full OFL 1.1 text, the same licence every family here carries.

- Anton, by Vernon Adams and the Anton Project Authors.
- Nunito Sans, by Vernon Adams and Jacques Le Bailly (variable file, weights 200 to 1000).
- Noto Sans, by the Google Noto project (variable file), used only for the African letters Nunito Sans lacks.
- Fraunces, by Undercase Type (Phaedra Charles, Flavia Zimbardi).
- Noto Sans Ethiopic, by the Google Noto project.
- Noto Sans Arabic SemiBold, by the Google Noto project, used by the map videos only. `OFL-Noto-Arabic.txt` is the licence file shipped with it, with its own copyright line.

Noto Sans comes from the Google Fonts repository (`ofl/notosans`); the other files come from `social/brand/fonts/` in the EthniAfrica repository, except Noto Sans Arabic.

Noto Sans Arabic SemiBold comes from the official notofonts release `NotoSansArabic-v2.013` (tag commit `1b2b7e5c6ce3ab4d50681c854892325530084c35` of `notofonts/arabic`, published 15 October 2025): the file `NotoSansArabic/full/ttf/NotoSansArabic-SemiBold.ttf` of https://github.com/notofonts/arabic/releases/download/NotoSansArabic-v2.013/NotoSansArabic-v2.013.zip. The archive's SHA-256 is `1301aceaea84c501cf2e6dcfb3182e2328c8eae5725817fcb239672bda7154f1`; the font file's is `a1548f8031214d637c2f5fc65c279cba7baf4673ea6f14e81b073ef2f8bae1b7`.
