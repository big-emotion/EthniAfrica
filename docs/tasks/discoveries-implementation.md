## Remaining release dependencies and rollback

The two existing Anecdotes are the only current feed publications. Source-library carousels and proverbs require editorial source checks, image rights, bilingual text, slide order and accessible captions/transcripts before addition. Compatible still/video exports require approved masters and validation of dimensions, MIME, credit, watermark and rights. This dependency blocks those content types and media actions, not the independent two-item reader implementation. Release readiness also requires the manual accessibility and visual review noted above. Rollback is an application revert of the new route/navigation and its local components; existing Anecdotes permalinks and its shared content bank are retained.

The local Node runtime is 25 although the repository pins Node 22. Run test commands with `NODE_OPTIONS=--no-experimental-webstorage` here: without it Node 25's experimental global storage makes 13 unrelated tests fail because `clear()` is missing. The existing full-tree translation-parity survey has 821 pre-existing findings/873 declared deferrals; the staged changed-files gate is the relevant new-work check.

The missing-image capture was made by dispatching an image error in the production browser after the photo had been cached; it is a simulated failure state, not evidence that a network request was blocked. It preserves a 390×612 stage and readable copy. A later red metadata check showed that the `fr` and `x-default` alternate links lagged behind the active publication; the corresponding test now passes after the links are updated with the URL and social metadata. The first two full-check attempts also exposed the pre-existing `node --test social/tools/` script's directory-as-file failure on Node 25 and 22. Running test discovery from `social/tools` passed all 38 tests, then the npm script was corrected to do so.

The pre-commit copy-literal guard then rejected inline reader and navigation strings. The bilingual Découvertes dictionary now owns those strings and the two short photo credits, is registered with the copy parity suite and translation façade, and passes both the staged copy-literal guard and 23 focused copy/reader/route tests. No localization gate was disabled.
