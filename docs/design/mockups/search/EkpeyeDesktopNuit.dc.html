D'où vient ce nom

Ekpeye

Un seul nom, porté de l'intérieur comme de l'extérieur.

Le nom Ekpeye est l'unique dénomination usitée, tant en interne que dans les sources officielles et académiques nigérianes.

Référencée

Ce que l'atlas tient

FamilleBenoûe-Congo — branche igboïde
RégionEkpeyeland, Ahoada, delta du Niger
PaysNigeria
Sources6

Ce que l'atlas ne dit pas

Un silence déclaré, pas un oubli.

Aucune autre appellation

L'atlas n'a trouvé aucun autre nom donné de l'extérieur.

Origine non documentée

Aucune source lue ne dit d'où il vient, ni ce qu'il voulait dire.

Aucune date

On ne sait pas depuis quand ce nom est écrit.

Appeler quelqu'un comme il s'appelle ne retire rien à personne.

C'est le geste le moins coûteux qui soit — et ici, le nom que les Ekpeye se donnent est celui que tout le monde emploie.

Nous nous sommes trompés ?

Si vous connaissez une source sur l'un de ces noms, elle sera lue.
