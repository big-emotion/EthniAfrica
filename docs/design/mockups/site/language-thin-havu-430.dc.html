Usage contemporainLe nom kihavu est formé comme beaucoup de noms de langues bantoues : le préfixe ki- devant le nom du peuple, ici les Havu.

Le nom kihavu est formé comme beaucoup de noms de langues bantoues : le préfixe ki- devant le nom du peuple, ici les Havu. Dans les langues kongo, ki- marque ainsi la langue et ba- les membres du groupe, selon Salikoko Mufwene. Glottolog recense les formes Kihavu et Haavu. On ne sait pas avec certitude d'où vient le nom Havu ; la fiche du peuple Havu présente ce peuple.

  • Glottolog 5.3 — Havu (havu1238) · Glottolog · Référence linguistique
  • Kikongo-Kituba, Atlas of Pidgin and Creole Language Structures Online · Salikoko S. Mufwene · Publication académique
