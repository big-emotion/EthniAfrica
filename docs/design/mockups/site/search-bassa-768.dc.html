D'où vient le nom · Peuple

Bassa

Le nom Bassa désigne un peuple de langue krou du Liberia, qui se nomme lui-même Bassa, Ɓǎsɔ́ɔ̀ dans sa langue. On ne sait pas avec certitude quand le nom a été écrit pour la première fois. Son origine est racontée dans un récit oral que nous présentons plus bas.

Le nom de ce peuple du Liberia ; son origine reste discutée.

L'origine du nom Bassa n'est pas datée dans le projet pour l'instant.

↓ On remonte le temps

  • Contemporain
  • Précolonial

  1. Usage contemporain

    Le nom Bassa se dit Ɓǎsɔ́ɔ̀ dans la langue de ce peuple : le dictionnaire bassa-anglais publié au Liberia traduit Ɓǎsɔ́ɔ̀-nyɔ̀ par « une personne bassa ». 

  2. Rapporté en 2013

    Le nom Bassa viendrait de Bah Saw Nyohn Bey, « les gens de Monsieur Roche » : c'est ainsi que se nommaient les serviteurs d'un chef qui commerçait avec les Européens, et ceux-ci l'auraient abrégé en Basa, selon un récit d'Abba Karnga. Le dictionnaire bassa-anglais traduit bien ɓǎ par « père » et sɔ́ɔ̀ par « roche ». 

  3. 1904

    Le nom Bassa figure, avec la forme Gbasa, chez Maurice Delafosse, qui place les Gbasa ou Bassa sur la côte du Liberia, de Bafou à la Junk River, dans la région de Grand-Bassa et d'Edina. 

  4. Avant le nom Bassa

    Avant l'arrivée des commerçants européens

    Le nom Bassa n'est pas encore employé : on parle du territoire de Gboo, du nom d'un ancien chef puissant, et de ses habitants comme des Gboo Nyohn Bey, « les gens de Gboo », selon un récit d'Abba Karnga. 

Fin de ce que nos recherches retracent pour le nom Bassa.

D'où vient le nom · Peuple

Bassa Nge

Le nom Bassa Nge désigne un peuple de langue nupe des rives du Niger, autour du confluent du Niger et de la Bénoué, dans l'État de Kogi, au Nigeria. Il ne faut pas le confondre avec les Bassa du Liberia ni avec les Bassa du Cameroun. Nous n'avons pas trouvé de source qui dise comment ce peuple se nomme lui-même. La plus ancienne trace sûre date de 1919 : une notice de deux administrateurs britanniques écrit « Nge or Bassa-Nge ». Une association du peuple explique le nom par les administrateurs coloniaux. Nous présentons plus bas l'histoire de ces noms.

Le nom officiel du peuple, qui le distingue des autres Bassa.

↓ On remonte le temps

  • Contemporain
  • Colonial
  • Précolonial

  1. Naissance du nom Bassa Nge · origine la plus ancienne connue du projet

    1919

    Le nom Bassa Nge figure en 1919 dans la notice que les administrateurs O. et C. L. Temple consacrent à ce peuple, sous le titre « Nge or Bassa-Nge ». La notice s'appuie sur le capitaine F. Byng-Hall. C'est la plus ancienne trace de ce nom que le projet connaît. Le peuple existait avant elle. 

    Personnes citées dans ce récit : Capitaine F. Byng-Hall, source de la notice de 1919

  2. Date inconnue

    Bassa Nge est, selon l'association Bassa Nge Community North America, un nom reçu des administrateurs coloniaux britanniques. Ils auraient appelé « Bassa » toutes les tribus de l'ancienne province de Bassa, puis ajouté à chacune un suffixe, « Nge » ou « Komu », pour les distinguer. L'association précise que les deux groupes n'ont « rien en commun » dans leur origine, leur culture ou leur histoire. 

  3. Usage contemporain

    Bassa Nge est le nom que l'association de la diaspora de ce peuple emploie pour elle-même, dans le nom de l'association et dans son récit d'histoire. 

  4. Avant le nom Bassa Nge

    Vers 1840-1850, selon la notice de 1919

    Avant le nom Bassa Nge, la notice de 1919 place dans les années 1840-1850 le départ des Nge de la région de Kabba : ils payaient un tribut à l'émir de Bida, puis, sans esclaves pour le payer, ils fuirent sur les collines, et la moitié du peuple traversa le Niger pour s'installer près de Gbebe. 

Fin de ce que nos recherches retracent pour le nom Bassa Nge.

D'où vient le nom · Peuple

Bassa

Le nom Basaa est celui que se donne un peuple bantou du Littoral et du Centre du Cameroun. On l'écrit aussi Bassa, comme le nom d'un autre peuple, les Bassa du Liberia, dont la langue appartient à une autre famille. Les sources consultées n'expliquent pas l'origine du nom ; nous présentons plus bas l'explication qui circule.

Une autre écriture de Basaa, que porte aussi un autre peuple, au Liberia.

L'origine du nom Bassa n'est pas datée dans le projet pour l'instant.

↓ On remonte le temps

  • Contemporain
  • Colonial

  1. Usage contemporain

    Le nom Bassa désigne aussi un autre peuple, les Bassa du Liberia et de Sierra Leone. Leur langue appartient à la famille krou, alors que celle des Basaa du Cameroun est bantoue : malgré la même écriture, nos sources n'établissent aucun lien entre ces deux peuples. 

  2. 1950

    Le nom Bassa est celui qu'emploie Louis-Marie Pouka, lui-même bassa, pour présenter un peuple bantou divisé en clans et « répandu un peu partout au Cameroun ». 

  3. Avant 1912

    Le nom Bassa est déjà en usage quand Georg Schürle l'écarte au profit de Basa : dans cette langue, explique-t-il, les deux a sont longs, et doubler le s n'a pas de sens. 

Fin de ce que nos recherches retracent pour le nom Bassa.

Ce peuple se nomme lui-même Basaa. Ce nom a aussi son histoire.
