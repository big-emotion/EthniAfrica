# Reader demand journal — 2026-10-24

Thirteenth run of the nightly demand pass. It measures what readers search and read
in Plausible, measures how empty each demanded fiche still is in git, and
enriches the most read and emptiest ones. Consented sessions only: every figure
is a floor, never the audience. Fiches are judged **from git (`recette`)**,
never from the live site.
