# Essais — la base idéologique, série par série

Un essai capture la raison d'être d'un angle éditorial précis, discutée avec
l'opérateur — pas la thèse centrale du site (`../purpose-doctrine.md`), et pas
une règle de gabarit ou de structure (celles-ci vivent dans
`docs/design/gabarits-social/GABARITS-SOCIAL.md` et les skills de la chaîne
`idee → structure → produire`). Écrit et tenu à jour par la commande
`/essai`.
