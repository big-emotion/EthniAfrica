# Self-names to verify through oral sources

A `nameHistory` name marked `selfGiven: true` says the people use that name for
themselves. For the names below, the fiche asserts it but no source we opened
states it. The operator ruled on 2026-10-10 to keep `selfGiven: true` rather
than drop a claim that is probably right, and to check each one with the
people concerned (oral sources, fieldwork, a speaker of the language) before
treating it as settled. Removing the flag without that check would trade one
unsupported statement for another.

| Fiche         | Name    | What is missing                                                                                                                      |
| ------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `PPL_SHONA`   | Shona   | a source stating the people use the name for themselves; the government of Zimbabwe says it was given by enemies in the 19th century |
| `PPL_IJAW`    | Izon    | a source stating Izon is the self-name                                                                                               |
| `PPL_IBIBIO`  | Ibibio  | same                                                                                                                                 |
| `PPL_BETI`    | Béti    | same                                                                                                                                 |
| `PPL_SAWA`    | Sawa    | same                                                                                                                                 |
| `PPL_MONGO`   | Mongo   | same                                                                                                                                 |
| `PPL_AMBUNDU` | Ambundu | same                                                                                                                                 |

## Related case: Bilād Ṣinqīṭ (`MRT`)

`MRT` marks Bilād Ṣinqīṭ as self-given. The operator asked for a Mauritanian
source that says so. None was opened on 2026-10-10, so the account now says
plainly that the point is not confirmed. A Mauritanian source that states it
(for example a reading of Aḥmad ibn al-Amīn al-Shinqīṭī's _al-Wasīṭ_, 1911)
would settle it; until then it stays on this list.
