## Before editing a profile

1. **Record the current string** in the "Before" column, with the date. The
   reason is reversibility: a profile editor keeps no history.
2. Paste the proposed text and **check the platform's own preview**. The counts
   below are Unicode code points measured on the exact text; each editor counts
   its own way, and its preview is authoritative.
3. Where the platform offers a dedicated link field, use it and drop the domain
   from the text rather than showing two destinations.
