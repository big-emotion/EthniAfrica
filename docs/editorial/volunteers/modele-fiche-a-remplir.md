# Modèle de fiche à remplir

_Brouillon du 3 octobre 2026. Copiez ce modèle dans un document, remplissez ce
que vous savez, et laissez vide ce que vous ne savez pas en le disant dans la
partie 8. Un champ vide et déclaré vaut mieux qu'un champ deviné._

Une fiche EthniAfrica tourne autour d'un nom : d'où il vient, sous quelles formes
on le connaît, et l'histoire de chacune de ces formes. Tout le reste est au
service de cette question.

Pour chaque information, indiquez sa source dans la colonne prévue, sous la
forme d'un **numéro** qui renvoie à la liste de la partie 9.

---

## 1. Le nom

| Question                                                                         | Réponse |
| -------------------------------------------------------------------------------- | ------- |
| Le nom, tel qu'on le cherche le plus souvent                                     |         |
| C'est le nom de : un peuple · un pays · une langue · un nom de famille · un lieu |         |
| Cette fiche existe-t-elle déjà sur EthniAfrica ? Si oui, son adresse             |         |

## 2. Le nom qu'il se donne

Pour un peuple ou une langue : comment ses membres ou ses locuteurs se nomment
eux-mêmes. Pour un nom de famille : comment ses porteurs l'écrivent et le
prononcent. Pour un pays : le nom dans la ou les langues du pays.

| Question                                                                           | Réponse | Source n° |
| ---------------------------------------------------------------------------------- | ------- | --------- |
| Le nom, dans la langue concernée                                                   |         |           |
| Dans quelle langue                                                                 |         |           |
| Ce qu'il veut dire, si une explication existe                                      |         |           |
| Si vous ne le connaissez pas, écrivez « non documenté » plutôt que de laisser vide |         |           |

## 3. Les autres noms, et l'histoire de chacun

Une ligne par forme : les noms donnés par des voisins, des voyageurs, des
administrations coloniales, des cartes, et les orthographes différentes.

| Forme du nom | Qui l'a donnée ou l'utilise | Depuis quand | Ce qu'elle veut dire, si on le sait | Pose-t-elle un problème (péjorative, coloniale, contestée) ? Pourquoi ? | Source n° |
| ------------ | --------------------------- | ------------ | ----------------------------------- | ----------------------------------------------------------------------- | --------- |
|              |                             |              |                                     |                                                                         |           |
|              |                             |              |                                     |                                                                         |           |

S'il n'en existe aucune à votre connaissance, écrivez « aucune connue ».

## 4. D'où vient le nom

Écrivez **une piste par ligne**. Si plusieurs explications existent, notez-les
toutes, sans en choisir une. Les récits oraux et locaux comptent autant que les
écrits, avec leur source.

| Piste (une phrase) | Qui la rapporte (auteur, porteur de la tradition, communauté) | Source n° |
| ------------------ | ------------------------------------------------------------- | --------- |
|                    |                                                               |           |
|                    |                                                               |           |

Si l'origine n'est pas établie, écrivez-le en une phrase : c'est une réponse.

## 8. Ce que nous ne savons pas

Ce que vous avez cherché sans le trouver, et ce que les sources ne permettent
pas d'affirmer. Cette partie est aussi importante que les autres.
